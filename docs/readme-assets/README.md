# README image provenance

The SVG artwork illustrates the workflow. The PNG images below are browser captures of HTML generated by the existing ShadowVendor application; chart values and styling were not redrawn or restyled.

- `dashboard.png` and `vlan-analysis.png`: [12-entry synthetic sample](../examples/mac-table.txt).
- `vlan-device-count.png`, `vlan-vendor-diversity.png`, `vendor-vlan-heatmap.png`, and `vlan-review-dashboard.png`: [48-entry synthetic sample](../examples/vlan-review.txt).
- The three detail images are rectangular screenshot crops from the application's four-panel VLAN figure. The heatmap includes a real mouse-hover tooltip. The complete screenshot retains the shared legend and color scale.

To reproduce, follow the root README's installation and bundled-cache setup, then run either:

```bash
python ShadowVendor.py --offline docs/examples/mac-table.txt
python ShadowVendor.py --offline docs/examples/vlan-review.txt
```

Each run replaces `output/vendor_distribution.html`. Open it in a browser with access to the Plotly CDN. The captures used the repository's bundled OUI snapshot, Python 3.14, Plotly Python 7.1.0, and Chromium on macOS. CDN updates, browser sizing, or a different vendor cache may change the appearance or labels.

The larger example has VLAN totals of 12, 8, 18, and 10, and vendor diversity of 3, 2, 4, and 2, for VLANs 10, 20, 30, and 40. The inspected heatmap cell is Dell / VLAN 30 / 4 entries. These are synthetic demonstration records, not measurements of a production network.
